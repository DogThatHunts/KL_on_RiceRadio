One of the 14 transcripts — 14 (He Cracked Every Layer of Reality) — contains no legal/tax citations; it is an unrelated third-party video essay, not a genuine KL episode (see the note in KL-ideas-RiceRadio.md).

Conflicts noted

Internal repetition within this project (the same lecture given in files 03 and 05, and again referenced in 07) was consistent in substance, only varying in how badly the case name was mis-transcribed from file to file (e.g. "Bruce Shaver" for Brushaber, "Caja" for Caha, "Twain"/"20" for Twining — all noted per-row above as as-spoken text, not treated as conflicts since they're the same speaker giving the same information, garbled by transcription rather than disputed).

Sánchez Valle's year is spoken as "2015" in both RiceRadio occurrences (files 03 and 05), same as the already-noted year discrepancy on the existing register record (decided 2016) — this project's occurrences reinforce rather than resolve that mismatch.
