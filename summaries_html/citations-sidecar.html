Citations sidecar — KL on RiceRadio (RiceTVX / Stranger Than Fiction)

Extracted per transcripts/prompts/extract_citations.md from all 13 transcripts in transcripts/TXT/. Cross-checked against ~/Projects/citation-register/register.json (schema in that repo's SCHEMA.md) and ~/Projects/citation-register/TBD_later.md. New citations (not previously in the register) were written to ~/Projects/citation-register/pending/KL_on_RiceRadio_2026-08-15.json, in the same per-category record shape as register.json; citations that already existed in the register also got a sources[]-append entry in that same pending file (per the prompt's provenance note), so every citation below — new or existing — has a corresponding pending-file entry unless explicitly marked "not added" below.

Files are referenced by their leading number (01–13); full names are listed in transcripts/prompts/extract_citations.md. KL is the guest/educator throughout; Chris Rice (or another named co-host, e.g. on files 08–10) is the interviewer — citations below are consistently spoken by KL unless noted.

Two of the 13 transcripts — 11 (Unlearning The LIES About American History) and 13 (He Cracked Every Layer of Reality) — contain no legal/tax citations; both appear to share the same short intro passage and otherwise cover historical/personal narrative, not case law or code.

Conflicts noted

No two RiceRadio transcripts contradicted each other on the same citation's name, cite, or year in a way that wasn't already a known conflict from the KL_on_Crrow project (see TBD_later.md). Internal repetition within this project (the same lecture given in files 02 and 04, and again referenced in 06) was consistent in substance, only varying in how badly the case name was mis-transcribed from file to file (e.g. "Bruce Shaver" for Brushaber, "Caja" for Caha, "Twain"/"20" for Twining — all noted per-row above as as-spoken text, not treated as conflicts since they're the same speaker giving the same information, garbled by transcription rather than disputed).

One pre-existing register conflict is relevant background here even though this project didn't introduce it: Puerto Rico v. Sánchez Valle's year is spoken as "2015" in both RiceRadio occurrences (files 02 and 04), same as the already-noted year discrepancy on the existing register record (decided 2016) — this project's occurrences reinforce rather than resolve that mismatch.
