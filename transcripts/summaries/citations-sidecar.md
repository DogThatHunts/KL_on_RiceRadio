# Citations sidecar — KL on RiceRadio (RiceTVX / Stranger Than Fiction)

Extracted per `transcripts/prompts/extract_citations.md` from all 14 transcripts in
`transcripts/TXT/`. Cross-checked against `~/Projects/citation-register/register.json`
(schema in that repo's `SCHEMA.md`) and `~/Projects/citation-register/TBD_later.md`.
New citations (not previously in the register) were written to
`~/Projects/citation-register/pending/KL_on_RiceRadio_2026-08-15.json`, in the same
per-category record shape as `register.json`; citations that already existed in the
register also got a `sources[]`-append entry in that same pending file (per the
prompt's provenance note), so every citation below — new or existing — has a
corresponding pending-file entry unless explicitly marked "not added" below.

File **01** ("Session 1 Part 1") was added later (2026-11-12), after the original
13-transcript scan/merge — its two citations (one new: *Slaughterhouse Cases*; one
append: *Dred Scott v. Sandford*) are in a separate, not-yet-merged
`~/Projects/citation-register/pending/KL_on_RiceRadio_2026-11-12.json`. File **12**'s
transcript was also replaced later (2026-11-13) — it had originally been paired with
an unrelated third-party video's transcript by mistake; its citations (two new: the
*Federal Reserve Act of 1913* and the *National Emergencies Act of 1976*; one new
secondary authority: the *American Jural Society*; several appends to existing
records) are in the same not-yet-merged pending file.

Files are referenced by their leading number (01–14); full names are listed in
`transcripts/prompts/extract_citations.md`. KL is the guest/educator throughout;
Chris Rice (or another named co-host, e.g. on files 09–11) is the interviewer —
citations below are consistently spoken by KL unless noted.

One of the 14 transcripts — **14** (He Cracked Every Layer of Reality) — contains
**no legal/tax citations**; it is an unrelated third-party video essay, not a genuine
KL episode (see the note in `KL-ideas-RiceRadio.md`).

## Conflicts noted

No two RiceRadio transcripts contradicted each other on the same citation's name,
cite, or year in a way that wasn't already a known conflict from the `KL_on_Crrow`
project (see `TBD_later.md`). Internal repetition within this project (the same
lecture given in files 03 and 05, and again referenced in 07) was consistent in
substance, only varying in how badly the case name was mis-transcribed from file to
file (e.g. "Bruce Shaver" for Brushaber, "Caja" for Caha, "Twain"/"20" for Twining —
all noted per-row above as as-spoken text, not treated as conflicts since they're
the same speaker giving the same information, garbled by transcription rather than
disputed).

One pre-existing register conflict is relevant background here even though this
project didn't introduce it: `Puerto Rico v. Sánchez Valle`'s year is spoken as
"2015" in both RiceRadio occurrences (files 03 and 05), same as the already-noted
year discrepancy on the existing register record (decided 2016) — this project's
occurrences reinforce rather than resolve that mismatch.
